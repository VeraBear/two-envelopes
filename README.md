# The Envelope Room

An interactive explanation of the two-envelopes paradox, built for MIT 18.600.

It includes a playable envelope experiment, a conditional-probability and expected-value quiz, and a base slider ranging from 1/4 through 100.

## Run locally

Open `dist/index.html` in a browser, or serve the `dist` directory with any static web server.

## Put it on GitHub

Create a new empty repository on GitHub, then run these commands in this folder:

```bash
git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
git push -u origin main
```

You can then share the repository URL. The interactive site files are in `dist/`.
